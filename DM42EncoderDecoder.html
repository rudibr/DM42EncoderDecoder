Listing syntax

Line numbers (0001, 01▸, 01▶, 01◆) and the { n-Byte Prgm } header are optional; they are rebuilt on encode.
Comments start with ', ; or @ outside a string: STO 01 ' keep it, RTN ; done. Inside "it's; ok" they are text.
Strings: "TEXT", append with ├"MORE" or |-"MORE". Up to 15 characters. Line feed: [LF], escape: [ESC].
Arguments: STO 07, RCL ST X, STO IND 03, VIEW IND ST Y, RCL "NAME", XEQ IND "P".
Labels: LBL "MAIN", LBL 05, LBL A/a; KEY 1 XEQ 01, KEY -6 GTO 99, ASSIGN "X" TO 03 (or -03 shifted).
Numbers: 1.5ᴇ-3 or 1.5E-3, ᴇ3, comma decimals 14,1041. Synthetic registers 100–127 (RCL 122) are accepted.
ASCII is accepted: / * ^ -> <= >= != RDN CHS SIGMA+. Free42 extensions such as FUNC, LSTO, X=?, XSTR are supported, and Plus42's named instructions too.
Unknown bytes decode as XROM mm,ff or HEX F2 …, and those lines encode back to the same bytes.
Plus42 mode: ↑ in strings is byte 1E, 'A*B', `A*B` and EVAL 'A*B' are equations, 12_km is a unit value, and comments use ; or @. It turns on by itself when a decoded file needs it.
Several programs: each one ends with END. A missing final END is added for you.
Hide comments / Hide line numbers only change what a pane shows; encoding always uses the full text. A pane is read-only while hiding. Copy and Save .txt take what is shown.
